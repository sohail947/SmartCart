# 🛒 SmartCart – E-Commerce Web Application

SmartCart is a responsive e-commerce web application built using React and JavaScript. It provides a simple shopping experience where users can browse products, search and filter items, view product details, manage their shopping cart, and submit customer reviews.

The project is being developed step by step, with plans to integrate a backend and AI-powered customer support.

## ✨ Features

- **Product Listing:** Browse available products with images, prices, and ratings.
- **Product Search:** Search for products by name.
- **Category Filtering:** Filter products based on their categories.
- **Price Sorting:** Sort products from low to high or high to low.
- **Product Details:** View individual product information and descriptions.
- **Shopping Cart:** Add products, increase or decrease quantities, and remove items.
- **Cart Calculation:** Automatically calculate total items and prices.
- **Data Persistence:** Save cart items using browser localStorage.
- **Customer Reviews:** Submit, view, and delete product reviews.
- **Review Persistence:** Save customer reviews using localStorage.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.

## 🚀 Getting Started

Follow these steps to run SmartCart locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd SmartCart
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Visit:

```text
http://localhost:5173/
```
